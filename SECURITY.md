# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the live deployment. Older commits and personal forks are not maintained as separate supported releases.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use the repository's [private vulnerability reporting form](https://github.com/powerpinkk/ansem-frontline/security/advisories/new) so the report can be assessed before disclosure.

Include the affected URL or file, reproduction steps, expected impact and any safe proof of concept. Do not include private keys, API credentials, wallet seed phrases or unrelated personal data. You should receive an acknowledgement within seven days. Confirmed issues will be documented after a fix is available.

## Scope

The project has no wallet connection, accounts or trading capability. Reports about the browser application, dependency chain, Cloudflare relay, secret exposure, cross-site scripting, request validation or deployment configuration are in scope. Market latency, third-party API availability and illustrative combat outcomes are documented product limitations rather than security vulnerabilities.
